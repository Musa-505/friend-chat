Отправка сообщения другу в Friend Chat.

Формат: `/msg <имя друга> <текст сообщения>`

1. Первое слово аргументов — имя друга, остальное — текст сообщения.
2. Если текст сообщения пустой или похож на мусор из терминала (recap, monitor-логи, ⏺, «Ran N shell command», «Monitor started», «Thought for», системные сообщения) — спроси пользователя: «Что отправить <имя>?» и дождись чистого ответа. Используй этот ответ как текст сообщения.
3. Выполни команду и покажи результат:

```bash
FRIEND_PY=""
for p in "$HOME/friend-chat/friend.py" "$HOME/code/friend-chat/friend.py"; do
  [ -f "$p" ] && FRIEND_PY="$p" && break
done
python3 "$FRIEND_PY" send <имя> <текст>
```

Если друг не найден — подскажи пользователю посмотреть список: `/friend list`.
